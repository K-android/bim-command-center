Central Library Folder Structure & Guide
Dynamic Category Discovery

BIM Command Center automatically scans your Central Scripts folder. Top-level folders act directly as your Categories, and inside each category you place engine subfolders (Dynamo, PyRevit, Custom Addins, Grasshopper).

Recommended Folder Hierarchy
Central Scripts Folder/
├── Documentation/ ← Category Name
│ ├── Dynamo/ ← Engine Folder (.dyn)
│ │ ├── Renumber_Doors.dyn
│ │ └── Renumber_Doors.desc.txt ← (Optional) Description sidecar
│ └── PyRevit/ ← Engine Folder (.py)
│ └── Tag_All_Walls.py
├── Quality & QA/ ← Category Name
│ ├── PyRevit/
│ │ └── Audit_Unplaced_Rooms.py
│ └── Custom Addins/ ← Engine Folder (.dll or .lnk)
│ └── BIMHealthCheck.dll
├── Computational/ ← Category Name
│ ├── Dynamo/
│ │ └── Facade_Panels.dyn
│ └── Grasshopper/ ← Engine Folder (.gh / .ghx)
│ └── Parametric_Louvers.gh
└── Dynamo/ ← Direct Engine at root (Category = "Central Library")
    └── Sheet_Maker.dyn
Key Guidelines
• Dynamo Player: All .dyn scripts launch seamlessly via Dynamo Player, showing only input parameters and outputs without cluttering your screen with the node canvas.
• New Categories: Create any new top-level folder (e.g. Structural, MEP, Interiors) and it will immediately become an active category tile on your homepage.
• Optional Descriptions (.desc.txt): You can place a text file with the same name as your script (e.g. Renumber_Doors.desc.txt) to provide documentation and expected outcomes.
